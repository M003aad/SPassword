## Reporting a vulnerability

Please do not report suspected vulnerabilities in public issues.

1. If private vulnerability reporting is enabled for this repository, use GitHub's **Report a vulnerability** option on the repository's **Security** tab to submit a private report.
2. You may also email **188705139+M003aad@users.noreply.github.com**. Include a description of the issue, its impact, and steps to reproduce it, while avoiding any sensitive personal information.

If GitHub private vulnerability reporting is unavailable, use the email address above. Please allow the maintainer to investigate and coordinate a fix before publicly disclosing the issue.
