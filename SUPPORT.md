# Support

For help with SPassword:

1. Read the project [README](README.md) for installation and usage instructions.
2. Search **[add repository issues URL]** for an existing question or report.
3. If no existing issue covers your question, open a new issue at **[add repository issues URL]** with the SPassword version, browser and version, operating system, and steps to reproduce the problem. Remove passwords and other sensitive information before posting.

For security vulnerabilities, do not use public issues. Follow the private reporting instructions in [SECURITY.md](SECURITY.md).

No additional support channels have been specified.
